# База поставщиков 1688

Автоматический сборщик карточек товаров с 1688.com. Работает сам, по
расписанию, на бесплатных серверах GitHub (GitHub Actions) — не на
компьютере Сергея.

## Как это работает

- `crawler_1688.py` — сам сборщик: заходит на 1688, ищет по заданным
  китайским запросам, заходит в каждую карточку товара и сохраняет в
  `base_1688.sqlite` название, цену, фото (и отпечаток фото), данные о
  фабрике-поставщике (сколько лет на площадке, доля повторных покупателей,
  балл сервиса, доля отгрузок в срок, доля хороших отзывов) и бейджи.
- `.github/workflows/crawler.yml` — расписание: каждые 30 минут GitHub сам
  запускает короткий заход (~3 минуты активной работы), а затем сохраняет
  обновлённую базу обратно в этот репозиторий.
- Если 1688 просит войти в аккаунт или показывает капчу — сборщик не
  ломится дальше. Он записывает время блокировки в таблицу `block_log`
  внутри базы и просто завершает текущий заход. Следующий заход по
  расписанию сам проверит, прошло ли время "охлаждения", и либо продолжит,
  либо подождёт ещё.
- Уже собранные страницы и карточки не собираются повторно — при каждом
  новом заходе сборщик продолжает ровно с того места, где остановился.

## Ручной запуск

На вкладке **Actions** этого репозитория можно нажать **Run workflow**,
чтобы запустить сборщик прямо сейчас, не дожидаясь расписания.

## Настройки

Все основные настройки — вверху `crawler_1688.py`: список запросов
(`KEYWORDS`), сколько страниц листать, паузы между действиями, шаги
охлаждения при блокировке. Скорость и интервал заходов задаются в
`.github/workflows/crawler.yml` (`cron` и `CRAWLER_RUN_BUDGET_SEC`) — их
стоит увеличить, когда в `block_log` накопится статистика о том, какой
ритм 1688 реально терпит.
